# 戦史地図 — Pacific War Battle Map

太平洋戦争の戦いを「戦域」と「日本国内の動員地域」で結びつけて見られるインタラクティブな地図サイト（プロトタイプ）。

戦域図（太平洋中央の世界地図）上の赤い印をクリックすると、戦いの概要（戦闘期間・両軍の損害・主力部隊など）が表示され、同時に日本地図側で動員元の都道府県がハイライトされます。

## デモ

GitHub Pages を有効にすると、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 特徴

- **1ファイル完結**：`index.html` のみ。ビルド・サーバー不要、ダブルクリックでも開けます。
- **緯度経度で地点配置**：世界地図は太平洋中央の正距円筒図法。座標を書くだけで世界のどこでも印を打てます。
- **データ駆動**：戦いの情報は `BATTLES` 配列にまとまっており、項目を足すだけで戦いを増やせます。

## 戦いの追加方法

`index.html` 内の `BATTLES` 配列に追記します。

```js
{
  id:"iwojima",
  name:"硫黄島の戦い",
  period:"1945.2.19 — 3.26",
  lat:24.78, lon:141.32, label:"硫黄島",
  jpLoss:"約 21,000 名", jpLossNote:"",
  usLoss:"約 26,000 名", usLossNote:"戦死約7,000・戦傷約19,000",
  unit:"小笠原兵団（第109師団）",
  originLabel:"…",
  prefectures:["東京都"],        // 日本地図でハイライトする都道府県
  summary:"…"
}
```

`prefectures` のキー名は日本地図データの都道府県名（例: `"栃木県"`）と一致させてください。

## データ出典

- 世界地図: [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン, 110m admin0 countries）
- 日本都道府県: [dataofjapan/land](https://github.com/dataofjapan/land)

## 注意

戦没者数・部隊編成・動員地域はプロトタイプ用の**仮データ**です。一般公開する際は一次資料での裏取りを推奨します。
